# 캠퍼스 로고 자리

여기에 `knu.png` `ynu.png` `kmu.png` 를 넣으면 Astro 화면의 캠퍼스 이름 옆 표식이 **그 로고로 바뀝니다.**
파일이 없으면 색 + 두 글자 표식(경북 · 영남 · 계명)이 대신 뜹니다. 깨진 이미지는 보이지 않습니다.

- 파일명 = 캠퍼스 slug: 경북대 `knu.png` · 영남대 `ynu.png` · 계명대 `kmu.png`. 그 밖의 캠퍼스는 이름을 URL 인코딩한 값입니다.
- 정사각형 PNG(배경 투명) 128px 이상을 권합니다. 화면에서는 14~18px 로 줄여 씁니다.
- 로고는 각 학교 자산입니다. 쓰기 전에 학교 표기 지침을 확인하세요. 그래서 기본값으로 받아 두지 않았습니다.
